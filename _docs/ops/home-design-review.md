# PC 메인 화면 시안 — 2026-09-30

Bumm님 요청: 앞선 시안에서 더 나아가 디자인·사용성·글자 크기를 함께 재검토하고 로컬로 제시한다.
이 문서는 시안의 설계 근거다. 인계 원장은 기존 `HANDOFF_CURRENT.md` 한 곳을 그대로 쓴다.

## 첫 화면의 목적

처음 온 학생이 여섯 장면의 차이를 알아보고, 하나를 선택해 더빙을 시작하는 화면이다.
큰 소개 문구와 설명 상자 여러 개를 읽어야 했던 구조를 줄이고, 장면 선택에 시선을 모은다.
현재 단계는 상단의 `장면 선택 → 목소리 녹음 → 영화 저장`에 표시한다. 이것은 이동 메뉴가 아니다.

## 앞선 시안에서 바꾼 이유

| 문제 | 이번 시안 |
|---|---|
| 11~13px 설명과 안내가 작아 읽기 어려움 | 카드 설명 16px, 주요 안내 18px, 카드 제목 22~24px. 중요도가 낮은 안내도 14px |
| 움직이는 영상 위에 글자가 겹쳐 장면마다 가독성이 달라짐 | 영상과 설명 영역을 분리. 설명 영역은 단색 배경, 설명 대비 9.12:1 |
| 소개·세 단계 안내·선택 안내가 서로 경쟁 | 한 제목과 선택 안내, 상단의 간결한 단계 표시로 정리 |
| 의미 없는 장면 번호와 여러 색의 강조가 분산시킴 | 번호·색 띠·색 덮기를 PC 시안에서 제거하고, 선택 반응은 금색 테두리로 통일 |
| 큰 화면만 보고 만든 레이아웃 | 1366×768, 1440×900, 1920×1080에서 여섯 카드와 하단 안내가 모두 화면 안에 들어가도록 조절 |
| 클릭만 구현한 가짜 버튼 | 네이티브 버튼으로 탭·엔터·스페이스·접근성 이름 지원 |

카드 전체를 누를 수 있으며 오른쪽 화살표만 눌러야 하는 구조가 아니다. 미리보기 재생 표시는
영상의 실제 재생 상태에 연결한다. 동작을 예고하는 안내는 호버하기 전부터 보인다.

## 글자와 반응형

Pretendard 자체 호스팅을 유지한다. PC 글자 크기를 역할별 rem 토큰으로 묶고, 글자를 200%로
확대했을 때 줄바꿈과 세로 확장을 허용한다. 화면을 맞추려고 설명을 줄임표로 자르지 않는다.
짧은 노트북 화면에서는 영상 영역만 2:1로 조절하며 설명은 16px를 유지한다.

토스의 [Typography](https://tossmini-docs.toss.im/tds-mobile/foundation/typography/)에서 제시하는
역할별 크기·줄 높이·글자 확대 대응을 참고했다. 특정 회사와 동등한 품질을 인증받았다는 뜻은 아니다.
학생 대상 사용성 조사는 아직 하지 않았으며, 현재 결과는 코드 검사와 브라우저 확인 범위다.

## 검증 범위

- PC 3종, 모바일 375×812, 태블릿 1024×768: 가로 넘침과 페이지 오류 없음.
- PC 1024×768, 기본 1440×900, 기본 글자 200%, 확대 시 폭 축소에 해당하는 720×450:
  카드 설명이 잘리거나 화살표와 겹치지 않음. 좁은 PC 창에서도 새 디자인을 유지하고
  1,000px 미만에서는 2열, 540px 미만에서는 1열로 바뀐다. 터치 기기는 기존 레이아웃을 유지한다.
- 설명 글자와 배경의 대비 9.12:1. 웹 접근성 전체 인증이나 실기기 검증을 의미하지 않는다.
- 카드 재생 시점·터치 자동재생·스플래시·녹음·합성·저장 동작은 기존 검사로 확인한다.
- 새 라이브러리·이미지·웹폰트 다운로드는 추가하지 않았다. 실제 성능 측정은 이번 범위에 없다.

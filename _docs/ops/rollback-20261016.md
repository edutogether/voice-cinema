## 4. 미리보기 채널은 라이브를 건드리지 않는다

```bash
npm run build
npx firebase-tools@15.32.1 hosting:channel:deploy vc2 --only voice-cinema --expires 7d --no-authorized-domains --project inky-voice-cinema
```

- 채널 배포는 그 채널에 새 판을 만들 뿐 `live` 채널의 릴리스는 바꾸지 않는다. 함수는 올리지 않는다(위 명령에 functions 없음).
- `--no-authorized-domains`: 이 플래그가 없으면 채널 주소를 Firebase Auth 허용 도메인에 자동으로 넣는다(프로젝트 설정이 바뀜). 이 앱은 Auth를 쓰지 않으므로 넣지 않는다.
- 확인: 채널 배포 뒤 `hosting:channel:list`의 `live` 릴리스 시각이 `2026-10-10T14:53:14Z` 그대로이고 `version.json`이 `3e5e8d2…` 그대로인지 본다.
- 미리보기 주소에서는 업로드가 CORS(서버 허용 목록)에 막혀 «저장 → QR»이 기기 다운로드로 대신된다(결정 7 보충).

장르 클립 교체 안내 (운영자용 내부 문서)

클립 6종은 저장소의 `public/clips/` 폴더에 둡니다. 빌드(`npm run build`)가 이 폴더를
그대로 `dist/`로 복사해 배포합니다.

※ 이 안내문은 예전에 `public/clips/README.txt`로 있었는데, `public/` 아래 둔 파일은
   전부 그대로 공개 배포되어 누구나 주소로 열어볼 수 있었습니다(2026-09-08 감사에서
   발견). 내부 문서는 배포되지 않는 `_docs/` 아래에만 둡니다.

파일명은 반드시 아래와 같이 (소문자, .mp4) 맞춰야 합니다:

  fantasy.mp4     (판타지)
  animation.mp4   (애니메이션)
  horror.mp4      (호러)
  action.mp4      (액션)
  drama.mp4       (드라마)
  sitcom.mp4      (시트콤)

썸네일도 같은 이름으로 `public/clips/thumbs/<장르>.jpg`에 함께 넣습니다 —
홈 화면 카드는 평소에 이 이미지를 보여주다가, 마우스를 올렸을 때만 클립을 받아옵니다.

조건
· 코덱은 반드시 H.264 / AAC. H.265(HEVC)로 인코딩하면 브라우저에서 화면이 검게 나옵니다.
· 권장 길이 10초 내외.
· 대사가 없는 영상을 씁니다. 다만 오디오 트랙 자체를 지우거나 무음으로 바꾸지는
  마세요 — 완성본에는 학생 목소리만 들어가지만(-map 1:a:0), 스튜디오의 [미리 보기]
  에서는 학생이 이 원본 소리를 실제로 듣습니다.
· 6개 모두 필요합니다. 홈 화면 장르 목록은 코드(src/genres.ts)에 고정되어 있어,
  파일을 빼면 "준비중"으로 표시되는 것이 아니라 그 카드가 깨집니다.

교체한 뒤에 반드시 확인할 것
· `npm run build` — 서비스워커 프리캐시 목록과 캐시 버전이 자동으로 다시 생성됩니다.
· `npm run test:e2e` — 합성·저장 흐름이 그대로 도는지 확인합니다.
· 완성본 크기. 서버가 20MB(디코딩 기준)를 넘는 업로드를 거부합니다
  (functions/validate.js의 MAX_DECODED_BYTES). 2026-09-01 실측에서 완성본이
  12.8~13.0MB였으니, 클립이 그때보다 훨씬 길거나 고화질이면 이 한도를 확인해야 합니다.

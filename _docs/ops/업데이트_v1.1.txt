주요 변경
1. 인터넷 문제로 드라이브 저장이 실패해도 학생 체험이 멈추지 않음
   → 자동으로 부스 저장 QR로 전환, 파일은 outputs 폴더에 보존
2. 저장·녹음에 시간 제한 추가 → 화면이 영원히 멈추는 문제 원천 차단
3. 기동 시 클립 자동 점검 → HEVC(H.265) 등 재생 불가 코덱이면 경고 표시
4. 결과 파일명에 무작위 코드 추가 → 다른 학생 영상 주소 추측 불가
5. 잘못된 요청(장르 조작) 차단
6. config.json 을 메모장으로 저장해도(BOM) 정상 인식, 오류 시 한국어 안내
7. 행사장에서 IP가 바뀌면 태블릿용 보안 인증서 자동 재발급
8. 저장 버튼 연타 시 중복 업로드 방지, 다시 듣기 연타 시 소리 겹침 방지
9. 목소리-영상 싱크 개선

운영 유의사항 (행사 후)
- outputs 폴더와 드라이브 폴더의 학생 녹음 파일은 행사 종료 후 일괄 삭제하세요.
- 부스에는 "녹음된 영상은 본인 전달용으로 저장되며 행사 후 파기됩니다" 안내를 게시하세요.

`refs/archive/tags/<원래이름>`으로 옮겼다. `git tag` 목록과 GitHub 태그 목록에서는 안 보이지만
**커밋은 그대로 살아 있고**, 언제든 돌아갈 수 있다.

```bash
git checkout refs/archive/tags/voice-cinema-freeze-20260826   # 그 시점으로 이동
git for-each-ref refs/archive/tags                            # 옮긴 것 전부 보기
```

원격에도 같은 이름으로 올려두므로 이 저장소를 새로 클론해도 따라온다
(`git fetch origin 'refs/archive/*:refs/archive/*'`).

## ⚠️ 옮긴 `pre-react`를 꺼내 쓸 일이 생기면 — 그대로는 안 된다

행사용 앱이라 되돌릴 수 있는지를 실제로 따져봤고, **그대로는 안 된다.** 옮기기로 한 이유이기도
하지만, 나중에 아카이브에서 꺼내 비교할 사람이 이걸 모르고 되돌리면 부스가 멈춘다.

- 그 시점의 `functions/index.js`에는 **`voice.edutogether.kr`가 CORS 허용 목록에 없다**(0건 확인).
  정본 주소는 2026-09-09에 붙었기 때문이다. 그대로 되돌리면 **정본 주소에서 업로드가 전부 막힌다.**
- `firebase.json`의 배포 폴더도 `docs`다(지금은 `dist`).

**꺼내 쓴다면 "이 변경이 원인인가"를 가리는 비교 용도로만** 쓴다. 실제로 되돌려야 하면 CORS
항목을 다시 넣어야 한다.

```bash
git fetch origin 'refs/archive/*:refs/archive/*'
git checkout refs/archive/tags/voice-cinema-freeze-20260908-pre-react
```

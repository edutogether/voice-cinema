# 판타지 «빛의 결투» — «후회하게 해 주마 !» 목소리를 7.27 → 7.50초로 옮긴 방법 (2026-11-16)

Bumm님이 정정판 미리보기 채널을 보고 «후회하게 해 주마 !»의 목소리를 자막(7.45초)에 맞추라고 하셨다(11/16, 팀장 전달 — 3차에 7.45, 4차에 7.50).
완성본(`FAN-FINAL-v8.5-full.mp4`)에는 따로 된 목소리 파일이 없고 소리가 한 줄이라, 목소리 토막만 잘라 늦췄다. 이 폴더는 그 일을 다시 할 수 있게 남긴 기록이다 —
**앱 빌드 · 배포는 이 파일들을 쓰지 않는다.**

## 왜 남기나
`node tools/build-scene.mjs fantasy --film <완성본> --pause 13.9`로 판타지를 다시 만들면 소리가 완성본 그대로라 **목소리가 7.27초로 돌아간다**.
그때는 아래 순서를 한 번 더 한다(`.claude/rules/app.md` «완성본» 절).

## 무엇을 바꿨나
- 목소리 토막 V = [7.24, 8.15)초(7.27초에 말이 시작해 8.14초에 끝난다, 앞뒤는 조용한 틈)를 **D = 0.23초** 뒤로 옮겼다.
- 그 앞 배경음 [6.84, 7.24)초(0.40초, 목소리 없음)를 `atempo 0.634921`로 0.63초로 늘여 빈자리를 채웠다 — 같은 소리를 되풀이하지 않는다.
- 옮긴 V가 원래 [8.15, 8.38)초 자리(조용한 틈 + 8.28초부터 효과음)와 겹치는 곳은 둘을 더했다 — 효과음을 지우지 않는다.
- 바뀐 곳은 6.84~8.38초뿐이다. 영상은 다시 인코딩하지 않았다(`-c:v copy`, 영상 패킷 그대로).
- 녹음실 원판(`public/clips/fantasy.mp4`)과 합성용 원판(`public/clips/final/fantasy.mp4`)이 같은 소리다 — 소리 패킷 MD5 `d752ab5478a98ae5c6255910741b758e`.
- 자막은 `say('후회하게 해 주마 !', 7.45, 8.37)` — 끝 8.37초는 옮긴 목소리가 끝나는 때(8.14 + 0.23)다.

## 순서 (작업 폴더는 저장소 밖, 출력 경로는 `C:/Users/…` 모양으로)
1. `node prep.mjs <FAN-FINAL-v8.5-full.mp4> 13.9` — `tools/build-scene.mjs --film`의 소리 길을 그대로 되풀이해 `film.wav`(목소리 칸 −8dB)와 대조용 `same.m4a`를 만든다.
   `same.m4a`의 소리 패킷 MD5가 옮기기 전 원판의 소리 패킷 MD5와 같아야 다음으로 간다(같은 설정으로 다시 뽑았다는 확인).
2. `py shift.py film.wav shifted.wav 0.23` — 목소리 토막을 옮긴다(numpy 필요). «바뀐 곳 6.84 ~ 8.38초»가 찍힌다.
3. AAC로 굳힌다(길이 L = 완성본 길이를 30fps 프레임에 맞춘 값, 28.666666666666668초):
   `ffmpeg -i shifted.wav -t L -af apad,atrim=0:L -c:a aac -b:a 160k -ar 48000 shifted.m4a`
4. 두 원판에 소리만 갈아 끼운다(영상은 그대로):
   `ffmpeg -i <원판.mp4> -i shifted.m4a -map 0:v:0 -map 1:a:0 -c copy -movflags +faststart <새 원판.mp4>` — 녹음실 원판 · 합성용 원판 각각
5. 확인: 두 원판의 소리 패킷 MD5가 같은지, 영상 패킷 MD5가 옮기기 전과 같은지, 말소리 대역(300~3400Hz)으로 목소리가 7.50초에 시작해 8.37초쯤 끝나는지.

카드 미리보기(`previews/fantasy.mp4`)는 소리 트랙이 없어 바꿀 것이 없다.

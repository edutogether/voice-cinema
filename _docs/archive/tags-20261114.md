## 꺼내는 법

```bash
git fetch origin 'refs/archive/*:refs/archive/*'
git show --no-patch refs/archive/tags/<이름>      # 태그 메시지
git checkout refs/archive/tags/<이름>              # 그 커밋으로
```

새로 클론한 곳에는 `refs/archive/*`가 기본으로 따라오지 않는다 — 첫 줄을 먼저 돌린다.

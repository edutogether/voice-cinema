## 제약

- 🔴 **기준은 라이브 `5fb8017`의 2560 화면이다** — 2560×1305 화면을 바꾸는 수정은 넣지 않는다(설치 파일 아이콘 하나만 예외, Bumm님이 정한 자리). `wt-pcfit`의 `e1cf682`와 미커밋 세 파일은 쓰지 않는다. `--snapshot`으로 전 · 뒤 배치를 대조해 증명한다.
- 이미 정한 것은 그대로다: 스플래시 값, 메인 영상 16:9, PC를 키우지 않음, 휴대폰 첫 화면 배열(`app.md`), 녹음실 영상 잘림은 **그대로 둠**(Bumm님 답), 방침 문구는 10/20 그대로.
- `app.md` 규칙: 새 `vw`·`vh` 금지, 폭 · 높이 조건은 `@container app`, `getBoundingClientRect`는 화면 px, 크기 구간별 손질을 새로 만들지 않는다.
- 배포는 «배포 직전 한 줄 → 팀장 확인 → master push → CI 배포»뿐이다. 공개 설치 파일 교체도 같은 절차다.
- 라이브 측정에서 실제 업로드를 일으키지 않는다. 큰 파일(엔진 · 영상)은 라이브에서 받지 않고 같은 커밋의 로컬 파일로 답한다 — 돈이 드는 일 0건.
- 시험 창은 작은 모니터에서만, 모니터 잠금 규칙대로. 세션 설정 파일을 고치지 않는다. 비밀값을 출력하지 않는다.

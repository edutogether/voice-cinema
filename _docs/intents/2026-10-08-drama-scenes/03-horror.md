## 1. 시나리오

- **세계** — 불 꺼진 학교 도서관. 높은 나무 책장 사이로 창의 푸른 달빛이 들어온다.
- **나** — 도서관에 책을 두고 와 손전등을 들고 다시 들어온 아이.
- **상대 «스르륵»** — 도서관을 혼자 차지하고 싶은 장난꾸러기 유령. 사실은 같이 놀 친구가 필요했다.
- **맞서는 이유** — 스르륵이 «나가 !» 하며 책들을 회오리처럼 날려 나를 쫓아내려 한다.
- **끝** — 용기 내어 외치자 손전등 빛이 커지며 책들이 제자리로 돌아가고, 스르륵은 꼬마 유령이 되어 머쓱하게 웃는다. 불이 켜지자 숨어 있던 친구들이 나와 박수.
- **아이가 외치는 것** — 무섭지 않다는 용기의 한마디, 불을 켜는 주문.
- **톤** — 어린이용 호러: 으스스하지만 무섭지 않게. 피·끔찍한 얼굴·갑자기 튀어나오는 놀래킴은 없다. 마지막은 밝고 따뜻하게.

## 4. 음향

- **BGM**: 낮은 공간음과 오르골(으스스하지만 귀엽게) → ⑥에서 밝은 마림바로 바뀜. 빠르기 약 80 → 110 BPM. 찾는 말(무료 상업용 음원): `spooky music box kids`, `cute halloween`, `happy marimba`
- **BGM 큐**: 0.0초 시작(0.3초 페이드인) → 3.5–6.0초 −4dB(상대 대사 밑) → 8.0–11.5초 −8dB(아이 목소리 자리, 앞뒤 0.15초) → 11.5초 복귀·고조 → 14.0초 마무리 → 15.0초 끝(꼬리 0.3초 페이드)
- **효과음**:

| 시각 | 소리 | 찾는 말 |
|---|---|---|
| 0.6초 | 딸깍 — 손전등 켜짐 | `flashlight click` |
| 1.8초 | 삐걱 — 책장 | `wood creak` |
| 2.6초 | 바람(부드럽게) | `spooky wind soft` |
| 6.1초 | 펄럭펄럭 — 책장 넘어가는 소리 | `pages flutter` |
| 6.8초 | 회오리 | `whoosh swirl` |
| 8.1초 | 빛이 퍼지는 소리(작게) | `soft shimmer` |
| 11.7초 | 윙 — 바람이 잦아듦 | `wind down` |
| 12.6초 | 착착 — 책이 꽂힘 | `books slot in` |
| 13.1초 | 뿅 + 딸깍 — 작아짐, 불 켜짐 | `pop, light switch` |
| 14.0초 | 박수와 웃음 | `kids applause laugh` |

# 장면 더빙 2.0 기획서 — "상대가 먼저 말하고, 3·2·1 뒤에 내가 외친다"

> 상태 메모: **기획서 작성**은 팀장 지시(대표님 10/8)로 승인된 일이다. **제작(그림·영상·소리)과 코드 변경은
> 대표님이 이 기획서를 확정하신 뒤에** 시작한다. 확인 못 한 값은 `[확인]`으로 적었다.

## 1. 문제

대표님 말씀(10/8): «지금은 드라마도 대사도 너무 짧고 BGM도 없다. 내가 학생이라면 갑자기 뭔 대사를 뱉어.
상황을 주거나 상대방이 먼저 주는 대사를 주고, 거기서 잠깐 멈춰 3·2·1로 3초 생각하게 한 다음 대사를 뱉게
만들어야 한다.»

지금 클립은 6종 모두 **10초짜리 한 장면**(1280×720, H.264, 각 약 6MB)이고, 학생은 장면 전체 10초 동안
아무 맥락 없이 녹음한다. 다운로드 영상에는 학생 목소리만 들어가고 배경음·효과음이 없다.

## 2. 원하는 결과 (대표님 확정 흐름)

| 단계 | 앱에서 보이는 것 | 다운로드 영상(15초)에 |
|---|---|---|
| ① 미리보기 | 고르는 화면의 카드에서 장르별 "앞 장면" 몇 초가 무음으로 반복 | 들어감 |
| ② 고르기 | 아이가 누르면 다음 장면으로 이어짐 | — |
| ③ 상황 | 시점 전환(1인칭) → 상대 클로즈업 → **상대가 먼저 대사**(목소리+자막+효과음) → 상대의 행동 | 들어감 |
| ④ 멈춤 | «뭐라고 외칠까 ?» + 대사 보기 2개 + «나만의 대사도 좋아요» → 3 · 2 · 1 | **빠짐** |
| ⑤ 녹음 | «지금 소리치세요 !» + 남은 시간 막대(정해진 길이) | 아이 목소리만 ⑥ 첫 컷에 겹침 |
| ⑥ 결과 | 반격 → 겨루기 → 승리 → 환호 → 합성·저장(QR 등 기존 그대로) | 들어감 |

- 다운로드 영상 = **①③⑥ + 아이 목소리**, 15초. 멈춤·카운트다운·«지금 소리치세요 !»·보기는 넣지 않는다.
- 자막은 **상대 대사에만**. 아이 구간에는 자막도 미리 녹음된 목소리도 없다.
- BGM은 다운로드 영상에서 끊기지 않고 이어진다. 아이 목소리 구간만 BGM을 살짝 낮춘다.
- 6개 장르 모두 교체하되, **기준 품질에 못 미치는 장르는 기존 클립을 그대로 둔다**(장르별로 켜고 끔).
- 캐릭터·주문은 **우리만의 것**(저작권·상표가 걸린 작품의 캐릭터·주문·이름을 쓰지 않는다).

## 3. 공통 시간표 — 모든 장르가 같은 박자를 쓴다

장르마다 박자가 같으면 앱 코드·조립 도구·검사가 하나로 끝나고, 장르를 바꿔 끼우기 쉽다.

| 컷 | 다운로드 영상 구간 | 길이 | 내용 | 소리 |
|---|---|---|---|---|
| ① 미리보기 | 0.0–2.5초 | 2.5초 | 1인칭, 내가 힘을 모으는 장면 | BGM 시작, 효과음 |
| ③-1 시점 전환 | 2.5–3.5초 | 1.0초 | 1인칭으로 상대가 보임(원경) | BGM, 긴장 효과음 |
| ③-2 상대 대사 | 3.5–6.0초 | 2.5초 | 상대 얼굴 클로즈업, **상대가 말함 + 자막** | 상대 목소리(2.2초 안), BGM 조금 낮춤 |
| ③-3 상대 행동 | 6.0–8.0초 | 2.0초 | 상대 어깨 너머 시점, 나를 향해 공격·도발 | 효과음 크게 |
| ⑥-1 반격 | 8.0–11.5초 | **3.5초** | 1인칭, 내가 맞받아침 — **아이 목소리 자리** | BGM −8dB, 효과음 작게 |
| ⑥-2 겨루기 | 11.5–13.0초 | 1.5초 | 줄다리기처럼 맞섬 → 내가 밀어냄 | 효과음, BGM 복귀 |
| ⑥-3 승리 | 13.0–14.0초 | 1.0초 | 상대가 사라짐·물러남 | 효과음 |
| ⑥-4 환호 | 14.0–15.0초 | 1.0초 | 주변이 환호 | 환호, BGM 마무리 |

**앱 안 흐름의 시간**: ③ 5.5초 → ④ 보기(아이가 읽는 시간, 질문 4) → 3·2·1 3초 → ⑤ 녹음 3.5초 → ⑥ 7초
(아이 목소리를 ⑥ 첫 컷에 겹쳐 바로 들려줌) → 저장·QR. ④⑤ 동안 화면은 ③의 마지막 장면을 멈춘 채로 둔다
("총알 시간" 느낌, 공격이 내 앞에서 멈춰 있음).

**주인공은 끝까지 얼굴이 나오지 않는다(1인칭 — 손·소품·발만).** 남녀·나이 상관없이 모든 아이가 이입할 수 있고,
가장 어려운 "같은 사람 얼굴을 컷마다 똑같이 그리기"가 상대 한 명으로 줄어든다(질문 7).

## 4. 장르별 콘티

표기: 대사·문구의 느낌표·물음표 앞은 한 칸 띄운다(COMMON_STANDARDS §32). 상대 대사는 **2.2초 안에 말할 수
있는 길이**로 맞췄다(한국어 보통 속도로 약 10음절 안팎).

## 5. 영상 만드는 방법 — "키프레임 원화 먼저, 컷 사이는 영상으로 잇기"

### 5-1. 순서
1. **기준 그림(장르당 3장)**: 그림체 기준 1장 + 상대 캐릭터 시트 2장(정면·옆) — 이후 모든 그림에 참조로 붙여 넣는다
2. **키프레임(장르당 9장)**: 컷의 시작·끝 장면. 이웃한 컷은 끝·시작 그림을 함께 쓴다
   (① 2장, ③-1 1장, ③-2 1장, ③-3 1장, ⑥-1 1장, ⑥-2 1장, ⑥-3 1장, ⑥-4 1장)
3. **컷 영상**: "첫 장면·끝 장면을 주면 그 사이를 움직이는" 도구로 컷마다 만든다. 짧은 컷(1~1.5초)도 4~5초로
   만들어 필요한 부분만 쓴다
4. **조립**: 저장소의 조립 도구(`tools/build-scene.mjs`, 새로 만듦)가 컷 자르기·이어 붙이기, 자막 넣기,
   소리 섞기, 산출물 만들기를 **같은 명령 한 번**으로 한다(다시 만들 때도 같은 결과)

| 항목 | 장르당 | 6장르 | 다시 그리기 포함 예상 |
|---|---|---|---|
| 그림(기준+키프레임) | 12장 | 72장 | **약 110장** |
| 컷 영상 | 8컷 | 48컷 | 컷당 평균 3회 → **약 145회** |

### 5-2. 도구
- **그림: 대표님 ChatGPT(대표님 크롬)** — 기준. OpenAI 이미지 API는 쓰지 않는다(대표님 기각).
  대표님 구독 안이라 추가 비용은 없을 것으로 보이나, 사용 한도(몇 시간에 몇 장)는 `[확인]`.
  **대표님 크롬을 쓰기 전에는 반드시 팀장에게 먼저 한 줄로 보고한다**(무엇 · 몇 분/몇 장 · 비용).
- **영상(첫·끝 장면 지정)** 후보 — 둘 다 결제가 필요하다. **쓰기 전에 팀장에게 한 줄 보고**:

| 후보 | 공개 자료 기준 비용(결제 전 공식 페이지로 `[확인]`) | 이 일에 필요한 양 추정 |
|---|---|---|
| Kling(3.0) | 월 37달러 Pro = 3,000크레딧, 월 92달러 Premier = 8,000크레딧. 초당 6~12크레딧 | 145회 × 5초 × 6~12 = 약 4,300~8,700크레딧 → **Premier 1개월(약 92달러)** |
| Google Veo 3.1 | API 기준 소리 없는 영상 초당 약 0.2달러(1080p). 4·6·8초, 첫·끝 장면 지정 지원 | 145회 × 6초 × 0.2 = **약 175달러**(Flow 구독 크레딧 방식은 `[확인]`) |

- 두 도구 모두 **나오는 소리는 쓰지 않는다**(소리는 따로 만들어 섞는다).

### 5-3. 품질 기준 — 장르를 "켜는" 조건
- 상대 캐릭터의 얼굴·옷·소품이 컷마다 같다 / 손·얼굴이 뭉개지지 않는다 / 깜빡임·형태 녹아내림이 없다
- 자막이 읽힌다 / 아동 행사에 맞지 않는 표현(피·무기 위협·지나친 공포)이 없다
- 판정은 **대표님 시사**(장르별 15초 시사본으로). 미달이면 그 장르는 기존 클립 유지

### 5-4. 실패하면
- **컷 하나가 계속 실패** → 그 컷만 "키프레임 그림 + 카메라 움직임(밀어 들어가기·흔들림) + 빛 효과"로 대신한다.
  조립 도구에서 바로 만들 수 있어 추가 비용이 없고 그림이 일관된다. 1초짜리 ⑥-3·⑥-4는 처음부터 이 방식이 나을 수 있다
- **장르 전체가 기준 미달** → 그 장르는 기존 클립 유지(대표님 결정 4)
- **일정이 밀림** → 판타지부터 하나씩 완성해 켠다(아래 7장). 다 못 해도 된 장르만 행사에 나간다

## 6. 소리

| 구분 | 방법 | 출처 기록 |
|---|---|---|
| 상대 목소리 | **AI 음성**(한국어 캐릭터 음성 서비스 — 후보 Typecast·ElevenLabs, 상업 이용 플랜 `[확인]`) 또는 **교사 녹음**(같이교육, 무료·자연스러움, 녹음 동의서) | 서비스명·플랜·생성일·문장 |
| BGM | 상업 이용 가능·출처 표기 불필요한 무료 음원 우선(후보: Pixabay Music — 이용 조건 `[확인]`). AI 작곡 서비스는 권리 관계가 불분명해 쓰지 않는 것을 권함 | 파일·주소·작가·라이선스·받은 날·SHA-256 |
| 효과음 | Pixabay 효과음, Freesound는 **CC0만** | 위와 같음 |

- 출처는 `_docs/ops/scene-assets.md` 표에 남기고, 라이선스 화면 캡처·PDF는 `_media/licenses/`(로컬 보관, 배포 제외)에 둔다
- **음량 기준**: 완성본 −16 LUFS 근처, 상대 목소리는 BGM보다 확실히 크게, ⑥-1 구간 BGM −8dB(앞뒤 0.15초 부드럽게)
- **아이 녹음 처리**: 부스에서 아이들은 소리를 지른다 → 합성 때 낮은 웅웅거림 제거(고역 필터)와 찢어짐 방지(리미터)를 건다.
  실측으로 비용이 거의 없다(0.1~0.2초)
- **녹음하는 3.5초 동안은 BGM을 끈다(추천, 질문 6)** — 노트북 스피커 소리가 마이크로 다시 들어가면 완성본에서
  BGM이 두 번 겹쳐 울린다. 화면만 맥박치듯 움직인다

## 7. 앱 쪽 계획

### 7-1. 바꾸는 것
- **장르별 스위치**: `src/genres.ts`의 장르 설정에 새 장면 자료(파일 주소·시간표·보기 문구)가 있으면 새 흐름,
  없으면 지금 흐름. **장르마다 따로 켜고 끈다** — "기준 미달 장르는 기존 클립 유지"가 코드 한 줄로 된다
- **새 화면 상태**: 상황 재생 → 멈춤(보기) → 3·2·1 → 녹음(3.5초, 남은 시간 막대) → 결과 재생(아이 목소리 겹침) →
  "다시 하기 / 이대로 저장" → 저장·QR(기존 그대로)
- **장르당 파일**: 15초 완성본 원판 1개(①③⑥ + BGM·효과음·상대 목소리·자막, 아이 자리는 비어 있고 BGM이 낮춰져 있음),
  홈 카드용 미리보기 고리 1개(①, 작게), 멈춤 화면용 정지 그림 1장. 앱은 원판을 **구간별로 재생**한다
  (컷 경계마다 키프레임을 넣어 정확히 끊김). 장르당 약 8MB — 지금(클립+녹음실 사본 약 12MB)보다 작거나 비슷
- **합성**: 원판의 영상은 그대로 복사하고, 오디오는 원판 소리 + 아이 목소리(8.0초 지점에 맞춰 늦춤)를 섞어 다시 인코딩
- **바꾸지 않는 것**: 서버(업로드 검사·저장 이름·한도·자동삭제), QR·공개 주소 고지, 개인정보 처리, 홈의 무음 재생 원칙,
  서비스워커 구조, H.264/AAC

### 7-2. 합성 시간 — 실측(2026-10-08, 이 PC, 앱과 같은 ffmpeg.wasm)

| 방식 | 중앙값(범위) |
|---|---|
| 지금(10초, 목소리만 입힘) | **0.26초**(0.21~0.35) |
| 새 방식(15초, 원판 소리 + 아이 목소리 섞기 + 필터) | **약 1.8~2.3초** |
| 나눠 본 결과 | 영상 복사 0.09초 · **15초 오디오 AAC 인코딩 약 1.7초** · 섞기 필터 0.1~0.2초 |

- 시간은 대부분 **AAC 인코딩**에서 든다. CPU를 6배 늦추는 흉내는 합성이 도는 작업 스레드에 걸리지 않아
  **저사양 수치는 이 방법으로 얻지 못했다** — 학교·부스 노트북 실기기에서 재야 한다. 그 노트북의 한 코어 성능이
  이 PC의 1/3~1/4이라면 **약 6~9초**로 추정한다(`[확인]`)
- **아이는 기다리지 않는다**: 합성을 ⑥ 결과(7초)가 재생되는 동안 뒤에서 돌리면 대부분 가려진다
- 그래도 길면: 웹 오디오로 미리 섞고 인코딩만 맡기는 방식, 오디오를 모노로 줄이는 방식을 시제품에서 비교한다

### 7-3. 부스 한 명당 시간과 처리량
- 새 흐름: ③ 5.5초 + ④ 보기 약 5초 + 3·2·1 3초 + ⑤ 3.5초 + ⑥ 7초 + 저장·업로드 약 5~15초 + QR 찍기 약 15~20초
  → **약 45~60초**. 지금 흐름(미리보기 + 3·2·1 + 10초 녹음 + 저장 + QR)과 **비슷하거나 조금 짧다**
- 업로드 파일: 15초 약 7MB(지금 약 6MB) — 서버 한도 20MB 안. 서버 처리량은 그대로(하루 2000명 실측 통과 기준 유지)
- 부스 기기 예열: 엔진 + 장르 6개 원판을 미리 받아 둔다(운영 안내서에 "장르를 한 번씩 눌러 보기" 추가)

### 7-4. 검사
- E2E(가짜 마이크): 장르 하나로 ③→④→3·2·1→⑤ 3.5초 녹음→⑥→합성 끝까지, 완성본 길이 15초(±0.1초),
  **아이 목소리가 8.0~11.5초 구간에 실제로 들어갔는지**(파형 크기 확인), 멈춤 화면 문구가 완성본에 없는지
- 장르별 스위치: 새 자료가 없는 장르는 지금 흐름 그대로(기존 E2E 전부 통과)
- 실기기: 학교 노트북·안드로이드 태블릿에서 합성 시간 실측, 스피커 → 마이크 되울림 확인

## 1. 시나리오

- **세계** — 반짝이는 우주의 작은 우주 정거장. 창밖에 아이들에게 별사탕을 나눠 주는 «별사탕 행성»이 떠 있다.
- **나** — 정거장의 꼬마 우주 대원. 조종석에서 «별빛 장갑»을 낀다.
- **상대 «꽝꽝이»** — 장난꾸러기 거대 로봇. 별사탕 행성을 혼자 갖고 싶어 한다. 나쁘다기보다 떼쓰는 아이 같다.
- **맞서는 이유** — 꽝꽝이가 집게로 행성을 붙잡고, 말리러 온 정거장에 레이저 그물을 던진다.
- **끝** — 별빛 빔이 그물을 녹이고 꽝꽝이는 손바닥만 한 꼬마 로봇으로 줄어들어 꾸벅 사과한다. 우주 친구들이 박수.
- **아이가 외치는 것** — 별빛 장갑의 발사 구호, 친구를 지키겠다는 다짐.
- **톤** — 밝고 경쾌한 우주 모험. 로봇도 귀엽고, 부서지거나 다치는 장면은 없다.
- **그림 결** — 6장르 공통 2D 그림 결을 그대로 쓴다(대표님 원칙). 애니메이션다운 느낌은 사탕 색 팔레트와 통통 튀는 모양으로 낸다.

## 4. 음향

- **BGM**: 경쾌한 신스와 오케스트라가 섞인 우주 모험곡. 빠르기 약 120 BPM. 찾는 말(무료 상업용 음원): `space adventure cartoon`, `playful orchestral synth`, `kids adventure upbeat`
- **BGM 큐**: 0.0초 시작(0.3초 페이드인) → 3.5–6.0초 −4dB(상대 대사 밑) → 8.0–11.5초 −8dB(아이 목소리 자리, 앞뒤 0.15초) → 11.5초 복귀·고조 → 14.0초 마무리 → 15.0초 끝(꼬리 0.3초 페이드)
- **효과음**:

| 시각 | 소리 | 찾는 말 |
|---|---|---|
| 0.2초 | 장갑 끼는 소리 + 충전음 | `glove snap, power up charge` |
| 1.8초 | 삑 | `cute beep` |
| 2.6초 | 쿵 — 로봇 등장 | `robot stomp` |
| 6.1초 | 지잉 — 그물 발사기 충전 | `laser charge` |
| 6.6초 | 촤악 — 그물 발사 | `net shoot` |
| 8.1초 | 별빛 빔(작게) | `sparkle laser` |
| 11.6초 | 치이익 — 그물이 녹음 | `sizzle` |
| 12.6초 | 별가루 | `sparkle` |
| 13.1초 | 뿅 — 작아짐 | `pop shrink` |
| 14.0초 | 박수 | `applause` |
| 14.1초 | 짧은 팡파르 | `fanfare short` |
| 14.2초 | 폭죽(가볍게) | `party popper` |

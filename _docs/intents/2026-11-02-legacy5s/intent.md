# 임시 5초 영상(LEGACY_5S) — 영상만 장학사님 Kling 영상으로, 영상 위에서 녹음

## 문제

새 영상(FINAL_7S — 대표님 제작 8편)이 아직 완성되지 않아, 미리보기 채널 `vc2-ux`의 영상 자리에는 10/17 슬라이드 원판(그림을 이어 붙인 것)이 들어 있다.
대표님 말씀(팀장 전달): «전체 판을 이전으로 돌리라는 게 아니다. 새 영상이 아직 완성되지 않았으니, 처음에 장학사님이 준 Kling 5초 영상으로 영상만 다 바꿔 놔라.
미리보기는 그냥 보여 주고, 시작하자마자 3·2·1, 그다음 멘트, 그리고 녹음하게 해라. 영상 빼고는 전체가 완성됐다는 걸 보여 주고, 영상은 교체될 예정이라고 알려라.»

## 원하는 결과

- vc2-ux 판(화면 · 흐름)은 그대로, 영상 자리만 Kling 영상으로. 장르 · 제목과 영상의 짝은 저장소 기록으로 정하고, 짝이 없는 장르는 보고한다.
- 흐름: 미리보기는 영상을 처음부터 끝까지 → «장면 시작»은 바로 3·2·1 → 멘트 → 녹음. 영상과 녹음이 맞물리는 방식 · 길이는 5초 영상에 맞게 정한다.
- 10초 · 7.0초 멈춤(FINAL_7S) 코드는 남기고, 새 영상이 오면 설정만 바꿔 되돌린다.
- 미리보기 판에 «영상은 최종 영상으로 교체될 예정입니다» 한 줄(눈에 띄되 체험을 가리지 않게).

## 제약

- 라이브 배포 없음 — 미리보기 채널만, 배포 직전 한 줄(채널 · 만료일 · 바뀌는 것) → 팀장 확인. F3(vc2-ux 라이브 여부)는 Bumm님 결정 대기.
- 정식 주소 · 옛 주소 · Portal의 동작은 바뀌지 않는다(이 가지가 나중에 라이브로 가도 임시 영상은 켜지지 않게).
- 유료 생성 도구 · Higgsfield 금지 — 있는 영상만 쓴다.

## 확인한 사실(저장소 기록)

- 장학사님 Kling 영상 = 1.0 판의 무성 클립 6장르(액션 · 애니메이션 · 드라마 · 판타지 · 호러 · 시트콤), 9/1 `29cdeeb`, 백업 `_media/originals/2026-10-01`
  (1280×720 · 30fps · 소리 없음 −84 ~ −90dB). **길이는 5초가 아니라 각 10.077초**이고 Kling 5초 생성 두 토막을 이은 모양이다(판타지 4.97초 · 시트콤 5.97초에서
  장면이 바뀐다). 저장소 어디에도 5초짜리 파일은 없다.
- 1.0 판에는 장르별 대사가 없었다(«지금, 나만의 대사를 들려주세요» — 10초 내내 자유 발화). 1.0 제목은 있다(`78dc476` `src/genres.ts`).
- 짝: 2.0 장르 색은 1.0을 물려받았다(`src/genres.ts` 머리말) — 판타지 · 애니메이션 · 드라마는 같은 장르, 히어로 ← 액션, 스릴러 ← 호러, 스포츠 ← 시트콤.
  SF · 뮤지컬은 새 장르.

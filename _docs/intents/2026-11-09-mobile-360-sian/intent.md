# 휴대폰 360×800 개선 시안 — 메인 · 녹음실 · 완성 (배포하지 않음)

## 문제

Bumm님이 해상도 전수 캡처(`D:\Projects\_shared\ops\decisions-20261102\img\vc-all-res-1109\000-개선-모음표.md`)를 보고
360×800 휴대폰의 세 화면을 지목했다(팀장 전달, 2026-11-09).

- 메인: 로고 묶음이 크고 링크 줄과 위끝이 어긋남, 제목이 크고 아래로 처짐, 장면 카드가 제목과 «더빙하기» 사이 가운데가 아님
- 녹음실: «텅텅 빈 것 같은데, 큰 글씨 욱여넣기 말고»
- 완성: «모바일은 QR 말고 저장하기, 텅텅 빈 거 걱정»

## 원하는 결과

시안 가지 `sian/vc-mobile-360-1109`와 로컬 빌드에서만 만든다 — **master에 넣지 않고 배포하지 않는다.**
360×800(3배) 전 · 후 캡처를 결정판 Voice Cinema 탭에 올려 Bumm님이 항목별로 고르게 한다.

- 메인 1~3: 로고 묶음 작게 · 위끝을 링크 줄에 맞춤 / 제목 작게 · 위로 / 장면 카드를 제목과 «더빙하기» 사이 세로 가운데
- 녹음실 A~D: 메인의 로고 줄 + 단계 ② / 영상 왼쪽 아래에 장르 · 제목, 위 줄은 «← 다른 영화 고르기»만, 영상은 둥근 카드 /
  진행 막대에 내 차례 칸을 빨갛게, 아래에 짧은 대사 순서 / 단추를 화면 맨 아래, 그 위를 고르게. 글자 크기는 그대로
- 완성 A~D(휴대폰만, PC · 패드 · 설치판은 QR 그대로): 그림을 눌러 그 자리에서 재생, «내 영화 열기» 없앰 /
  «내 폰에 저장하기» 빨간 큰 단추(아이폰 공유 창 → «비디오 저장», 안드로이드 내려받기) / 받을 수 있는 날 한 줄(자동 삭제 일정에서) /
  «다른 더빙하기»는 흰 바탕 · 빨간 테두리

## 제약

- 메인 · 녹음실 배치는 앱 높이 720 이상 세로 휴대폰에만 건다 — 낮은 휴대폰 · 가로 · 태블릿 · PC는 그대로
- 녹음실 영상을 `cover`로 덮어 키우지 않는다(10/21 — 말하는 상대가 잘린다), 위아래 띠를 만들지 않는다
- 대사 데이터에 아이 대사 글이 없다(자유 발화) — 대사 순서는 상대 대사 + «내 차례»로만 보인다
- 완성 화면의 날짜는 `MAIL_PURGE_AT`(2026-12-01 00:00 KST)에서 계산한다 — 숫자를 따로 박지 않는다
- 아이폰 공유는 누른 손길 안에서 불러야 한다(앞에 await 없이)

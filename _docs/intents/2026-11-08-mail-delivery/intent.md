# 인터넷이 끊겼을 때 영화를 인솔 선생님 메일로 전달한다 — 설치판 시험판

## 문제

부스의 인터넷이 끊기면 지금은 «이 기기에 저장»으로 부스 노트북에 파일이 남는다. 학생에게 전하고 지우는 일이 전부 사람 몫이고, 끝내 안 지우면 아이 목소리가 공용 기기에 남는다.
Bumm님: «이메일 주소 받는 걸 설치판에 만들어야겠음», «실제로 구현되는 걸 봐야지 느낌이 올 것 같아», «교육청에서 알아서 할 거니 앱에다 덕지덕지 모든 걸 다 할 필요 없음».

## 원하는 결과

설치판에서 업로드가 실패하면 교사 · 운영자가 «이름 또는 별명» 한 칸과 인솔 교사 메일을 적는다. 다음 화면에서 주소를 다시 보여 주고 고칠 수 있다.
그 뒤 영상 · 이름 · 주소는 기기에 암호화해 잠시 보관한다. 인터넷이 돌아오면 영상을 올리고, 인솔 교사에게 링크를 메일로 보내고(교사당 한 통), 기기에서 바로 지운다.

이번에 만드는 것은 **시험판**이다. Bumm님이 직접 누를 수 있어야 하고, 끊김 → 입력 → 확인 → 대기 → 복구 → 발송 → 삭제가 실제로 돌아간다.
발송만 가짜다. 화면에 «보낸 것으로 처리»가 나오고 가짜임을 숨기지 않는다. 끝나면 시험판 경로와 단계별 실제 크기 캡처를 팀장에게 보낸다. 배포하지 않는다.

## 영향받는 사용자 · 시스템

- 공개 웹판과 공개 설치판은 바뀌지 않는다. 이 가지(`feat/vc-desktop-mail`)에서 만든 시험판에만 들어간다.
- 시험판은 프로그램 이름 · 앱 데이터 폴더가 따로라 설치된 Voice Cinema와 섞이지 않는다.
- 🟠 시험판에서 사람이 누르면 **영상 올리기는 실제로 일어난다**(QR과 같은 경로 · `dubs/` · 12/1 자동 삭제). 자동 시험과 캡처는 업로드를 가로채 실제로 올리지 않는다.
- 서버(`functions/`)는 이번에 고치지 않는다.

## 제약

- 공개 웹판에 넣지 않는다.
- 동의는 교육청이 맡는다. 동의 체크 · 동의 화면 · 긴 고지를 넣지 않고, 왜 받는지 알려 주는 짧은 한 줄만 둔다.
- 메일 발송 업체 계정 · 키 · 도메인 인증 · 비용은 Bumm님 몫이다. 세션이 만들거나 결제하지 않는다. 키를 설치판에 넣지 않는다.
- 공용 기기에서 다음 사람에게 이전 메일 · 이름이 뜨지 않는다. 실제 앱에서 시험한다.
- 로그 · 콘솔에 메일 주소와 이름을 남기지 않는다. 앱 데이터 폴더 어디에도 평문으로 남지 않는다.
- 대기 중인 영상 · 이름 · 주소는 AES-256-GCM으로 암호화하고 키는 OS 저장소(safeStorage · DPAPI)로 보호한다. 같은 Windows 계정의 다른 앱까지 막지는 못한다.
- `privacy.html`의 «받지 않는다» 문장은 시험판 단계에서 고치지 않는다. 고칠 곳과 문안만 보고한다.
- 화면 문구는 어린이 · 교사 대상 공식 행사에 맞게 쓰고 은어 · 속어 · 개발 용어를 넣지 않는다.
- 입력 칸은 조사 문서 `D:\Projects\_shared\ops\voice-cinema-20261017\mail-standard-20261107.md`를 따르되 꼭 필요한 것만 쓴다. 두 번 입력하지 않고, 도메인 오타는 경고만 하고 막지 않는다.

## 설계

- **화면**: `Result.tsx`의 «기기 저장» 자리. 대기열 다리(`window.vcDesktop.mail`)가 있을 때만 입력 → 확인 → 대기 화면을 보인다. 웹에는 다리가 없어 그대로다. «메일 없이 이 기기에 저장»은 보조 단추로 남긴다(막다른 길을 만들지 않는다).
- **보관**: `desktop/mail-store.js` — 건마다 영상 파일 하나와 정보 파일 하나를 쓴다. 정보 파일을 나중에 쓰므로 도중에 꺼져도 반쪽 건이 대기열에 오르지 않는다.
- **처리**: 렌더러의 `src/lib/mailDelivery.ts` — 업로드에 App Check 토큰이 필요해 화면 쪽에서 돈다. 영상 올리기 → 주소 기록 → 메일 보내기 → 지우기. 메일이 나간 뒤 지우기 전에 꺼지면 다음에 한 통 더 갈 수 있고, 그 대신 영상이 사라지지는 않는다.
- **재시도**: 30초에서 두 배씩 늘려 5분까지, 8번 실패하면 «보내지 못함»으로 빼 두고 운영자가 «다시 보내기»를 누른다. 인터넷이 돌아오는 신호가 오면 전부 처음부터 다시 시도한다.
- **삭제**: 보내면 바로. 못 보낸 것은 ① 운영자 «지우기» ② 2026-12-01 00:00(KST) 이후 처음 켤 때 전부(링크도 그때 죽고 방침의 보관 기한과 같다) ③ 프로그램 제거 때 앱 데이터와 함께.
- **실제 발송이 붙는 자리**: Functions에 메일 경로를 하나 더 두고 Resend 키는 Secret Manager에 둔다. 설치판은 BOOTH_TOKEN · App Check로 그 경로만 부른다. 이번에는 만들지 않는다.
